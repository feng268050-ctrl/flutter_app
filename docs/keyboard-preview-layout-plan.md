# Keyboard 预览页面：软件布局方案

**状态：已实现（软键盘预览；三布局 QWERTY / QWERTZ / AZERTY；JIS 已移除）**  
**范围：** `packages/cyber_ime` 的 Keyboard A（字母、数字/符号层与预览页）。本方案只定义触屏软件键盘；实体 HID 键盘的 XKB 布局、按键和设置流程不在范围内。

## 1. 目标与边界

将现有 Keyboard 预览页面从“实体打字机键盘缩略图”改为“产品实际会出现的手机式软件键盘”预览。预览必须复用线上键盘的布局、键帽和字符映射数据；不得再维护一套仅供展示的按键排列。

- 可选布局只有 **QWERTY、QWERTZ、AZERTY**；移除 `Default` / `defaultSoft` / **JIS** 的入口、标签和持久化值（旧 `jis` / `jp` 读作 QWERTY）。
- **QWERTY 是默认布局**：新安装、旧 `Default` / `JIS` 值、缺失或无法识别的值都归一化为 QWERTY。
- 所有字母布局均为三行字母区加一行底部功能区，不显示数字行、F1–F12、Tab、Caps Lock、Ctrl、Alt、AltGr、Win/Menu、方向键、实体 Enter 形状或独立数字小键盘。
- 保持现有 `CyberButton` 键帽、字体、色彩、间距、按压动画、长按弹层和输入提交事件；本改动只替换布局几何、层级和字符映射。
- **显示第二功能字符：** 已有 `CyberImeKeyDef.secondary` / KeyMap 的第二字符必须在实机键盘和预览中可见，不能只保留输入逻辑而不渲染键帽。QWERTY 字母层保留原有数字/符号第二功能提示；其他布局仅显示当前层明确配置的第二功能或重音提示。
- `123` 与 `#+=` 是唯一的完整数字/符号层级切换；`Shift` 只改变字母大小写，以及当前符号键的第二字符。QWERTY 保留原有数字/符号副标签和长按快捷输入；其他布局不把数字作为字母键副标签。

## 2. 预览页面信息架构

设置页 Segment 固定为：`QWERTY | QWERTZ | AZERTY`，初始高亮 QWERTY。删除旧 `Default` / `JIS` Segment；预览标题为“软件键盘布局预览”。

预览区展示当前布局的**字母层、未按 Shift 状态**，包含所有四行键位。预览为只读，不弹出长按候选、不切换层、不改变会话；但应使用与实机一致的键宽权重、行缩进、功能键图标/文案、第二功能字符和场景化确认键文案。页面下方说明：QWERTZ/AZERTY 显示“长按可输入重音字符”。

```text
Keyboard layout
[ QWERTY | QWERTZ | AZERTY ]

软件键盘布局预览
      Q  W  E  R  T  Y  U  I  O  P
        A  S  D  F  G  H  J  K  L
  ⇧      Z  X  C  V  B  N  M      ⌫
  123           Space             Next
```

预览中的 `Next` 仅为示意；实际文字取当前 `CyberImeAction`（例如 `Done`、`Search`、`Next`、`Enter`）。

## 3. 共用软件键盘骨架

### 3.1 行与宽度规则

以第一行普通字母键宽为 `1u`；各行可用宽度扣除现有统一间距后按权重分配。数值为设计基准，允许实现时因最小点击面积做等比例收缩。

| 区域 | 构成 | 宽度/对齐 |
|---|---|---|
| 第 1 行 | 10 个字母 | 10 × `1u`，居中 |
| 第 2 行 | 9 或 10 个字母 | 9 键时左右各缩进约 `0.5u`；10 键时与第 1 行对齐 |
| 第 3 行 | Shift、字母、Delete（AZERTY 另有撇号） | Shift/Delete 各 `1.5u`；其余空间分给字母，字母区居中 |
| 底行 | `123`、可选语言键、Space、场景化确认键 | `123` `1.5u`；语言键 `1.25u`；确认键 `1.8u`；Space 填满其余宽度 |

`Shift` 使用现有 Shift 图标并显示激活态；`Delete` 使用现有退格图标并支持现有长按连删；`Space` 插入空格。场景化确认键保留当前 `CyberImeAction` 的提交/换行事件，不能因布局切换而变成实体键盘 Enter。

### 3.2 键帽的第二功能显示

一个字符键若在当前层同时定义 `primary` 与 `secondary`（或 KeyMap 当前层的第二输出），键帽须同时渲染两者：主字符置中，以现有主字符字号显示；第二字符置于键帽上方，以现有弱化颜色和较小字号显示。第二字符不是独立按钮，不额外占用键宽，也不改变现有点击、长按、滑动选择或按压动画。

| 状态 | 主字符 | 第二功能字符 | 视觉反馈 |
|---|---|---|---|
| Shift 关闭 | 当前层 primary | 当前层 secondary | primary 居中；secondary 位于上方 |
| Shift 打开 | Shift 后输出 | 与该输出配对的第二字符（如有） | Shift 仍显示激活态；当前会被输入的字符应使用主字符视觉层级 |
| AltGr / 第三层 | 不适用 | 不适用 | 本软件键盘不显示 AltGr，也不以第三层隐藏第二功能 |

例如符号页中某键的 `primary='/'`、`secondary='?'`，预览与实机均应显示 `?`（上方）和 `/`（中间）；Shift 后输入 `?`。长按重音候选不属于键帽第二功能字符，仍只在长按弹层显示。

### 3.3 数字与符号层

所有三种布局使用同一套手机式两级符号页，且仍保留同样的底行宽度规则：

| 层 | 入口/退出 | 内容 |
|---|---|---|
| 字母层 | `ABC` 返回 | 各区域字母布局 |
| 数字/常用符号层 | `123` 进入 | `1 2 3 4 5 6 7 8 9 0`；常用 `- / : ; ( ) ￥ & @ “` 等；底行有 `#+=` |
| 扩展符号层 | `#+=` 进入 | `[ ] { } # % ^ * + = _ \\ | ~ < > € £ •` 等；底行 `123` 返回数字层 |

符号层的 `Shift` 仅在需要两字符键帽时切换该键的第二字符；不得承担 Caps Lock、AltGr 或第三层职责。QWERTY 字母键的第二功能是长按快速输入提示，不替代 `123` / `#+=` 分层。语言相关货币符号可以随区域替换（例如 QWERTY `$`、QWERTZ/AZERTY `€`），但不改变层级和按键数量。

## 4. 各布局的字母层

### 4.1 QWERTY（默认）

| 行 | 按键 |
|---|---|
| 1 | `Q W E R T Y U I O P` |
| 2 | `A S D F G H J K L`（相对第一行居中缩进） |
| 3 | `Shift  Z X C V B N M  Delete` |
| 底 | `123  Space  场景化确认键` |

Shift 关闭时输入小写，打开时输入大写；一次字母输入后依现有单次 Shift 规则复位。无旧 `Default` 手机键盘分支。

QWERTY 字母层继续显示原有的第二功能提示，实机与预览完全一致：第一行 `Q–P` 对应 `1–0`；第二行 `A–L` 对应 `~ ! @ # % " ' * ?`；第三行 `Z–M` 对应 `( ) - _ : ; /`。第二功能通过现有长按弹层选择，`123` / `#+=` 仍用于完整数字和符号层切换。

### 4.2 QWERTZ（德语）

| 行 | 按键 |
|---|---|
| 1 | `Q W E R T Z U I O P` |
| 2 | `A S D F G H J K L` |
| 3 | `Shift  Y X C V B N M  Delete` |
| 底 | `123  Space  场景化确认键` |

德语特殊字符不占常驻键位，使用基础字母的长按候选；Shift 打开时候选同步转为大写。至少提供：

| 基础键 | 小写候选 | Shift 候选 |
|---|---|---|
| A | `ä` | `Ä` |
| O | `ö` | `Ö` |
| U | `ü` | `Ü` |
| S | `ß` | `ẞ` |

### 4.3 AZERTY（法语）

| 行 | 按键 |
|---|---|
| 1 | `A Z E R T Y U I O P` |
| 2 | `Q S D F G H J K L M` |
| 3 | `Shift  W X C V B N  '  Delete` |
| 底 | `123  Space  场景化确认键` |

第三行的 `'` 是法语常用撇号键，位于 `N` 后、Delete 前；它是独立常驻软件键，不来自实体 AZERTY 的标点位置。

法语重音/连字均经长按候选输入，Shift 提供对应大写：

| 基础键 | 小写候选 | Shift 候选 |
|---|---|---|
| E | `é è ê ë` | `É È Ê Ë` |
| A | `à â æ` | `À Â Æ` |
| C | `ç` | `Ç` |
| O | `ô œ` | `Ô Œ` |

### 4.4 JIS（已移除）

软键盘不再提供 JIS / 罗马字布局。旧 `profile=jis` 或 XKB `jp` 读作 QWERTY。

## 5. 实现数据与迁移约束

建议以单一 `CyberImeSoftLayoutSpec`（或等价不可变数据模型）描述：字母行键序、左右功能键、底行能力、按键宽度、长按候选和区域符号偏好。`CyberImeKeyboardPanel` 与 `CyberImeLayoutPreview` 都由该规格渲染；预览不能继续调用实体键盘式 `CyberImeTypewriterLayouts`。

区域 profile 枚举和值迁移如下：

| 旧值 | 新值 |
|---|---|
| `defaultSoft` | `qwerty` |
| `ansi` | `qwerty` |
| `qwertz` | `qwertz` |
| `azerty` | `azerty` |
| `jis` / `jp` | `qwerty` |

推荐将 `ansi` 重命名为语义明确的 `qwerty`，并移除 `defaultSoft`。读取持久化配置时必须兼容以上旧字符串；写回时只写新三种值。语言类型（全局 English/Chinese）与区域键位仍保持正交。

## 6. 验收清单

- 预览 Segment 仅显示 3 项，首次进入为 QWERTY；旧 Default / JIS 配置进入后显示并保存为 QWERTY。
- 预览与实机键盘的每一行键序、缩进、Shift/Delete/Space/确认键宽度一致，且均无实体专用按键区。
- 任一当前层定义了第二功能字符的键，在预览和实机键盘均同时显示主字符与第二字符；Shift 后输入的字符与键帽显示一致。
- `123 → #+= → 123 → ABC` 各层切换正确；除 QWERTY 的既有副标签/长按快捷输入外，数字不出现在字母键副标签或长按候选中。
- QWERTZ 与 AZERTY 的长按弹层、滑动选择、Shift 大小写以及取消手势沿用现有交互；表中所有字符可被提交。
- 现有密码可见性、数字专用字段、提交动作、键盘高度和弹窗避让不回归。

## 7. 非目标

- 不模拟 ANSI/ISO/JIS 实体键帽几何，不新增数字行、功能行、导航区或 NumPad。
- 不改变 HID 键盘布局、XKB 配置或外接键盘事件。
- 不在本方案中定义完整日语词典来源、学习词频或云端联想；候选引擎以可替换接口接入，先满足本地罗马字转换与候选提交。

## Why

WiFi 详情页的“忘记/断开连接”确认对话框没有采用应用统一视觉风格，和其他页面（如设置时区弹窗）存在明显割裂，影响界面一致性和产品质感。需要尽快统一该关键交互弹窗样式，降低用户认知负担并提升体验连贯性。

## What Changes

- 调整 WiFi 详情页“忘记/断开连接”确认对话框的视觉样式，使其遵循应用统一弹窗设计规范。
- 对齐设置时区弹窗的关键样式元素（容器、标题、正文、按钮布局与状态）并在暗色主题下保持一致观感。
- 规范确认与取消按钮的层级与可用状态表现，避免当前弹窗与全局交互样式不一致。

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `wifi-network-details`: 更新“忘记/断开连接”确认弹窗的视觉与交互要求，确保与应用统一弹窗样式一致。

## Impact

- 主要影响 `app/src/main/res/layout/` 下 WiFi 详情与弹窗相关布局资源，以及对应 fragment/activity 的弹窗创建与样式绑定逻辑。
- 不涉及外部 API 或后端协议变更，仅影响前端 UI 表现与用户交互一致性。

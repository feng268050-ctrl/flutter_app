# ek3562 (RK3562 EVB2 DDR4 V10) — DTS drop + FIT / OEM 接入清单

**Hardware baseline (live board, 2026-08-15):**

| 项 | 值 |
|----|-----|
| model | Rockchip RK3562 EVB2 DDR4 V10 Board |
| compatible | `rockchip,rk3562-evb2-ddr4-v10`, `rockchip,rk3562` |
| console | `ttyFIQ0` @ **115200** (`fiq-debugger` baud `0x1c200`) |
| earlycon | `uart8250,mmio32,0xff210000` |
| Wi‑Fi | onboard RTL8821CU（见 `ek3562-wifibt.config` + OEM `wifibt-bringup.sh`） |

Host serial: `PORT=/dev/cu.usbserial* make serial-console`（TTL 默认 115200）。

## Overlay 落盘（已完成）

Git SoT under **`overlay/kernel/rockchip/`**（`make apply-overlay` → SDK `dts/rockchip/`）：

| File | Role |
|------|------|
| **`ek3562.dts`** | FIT / `board_id` 入口（产出 `ek3562.dtb`） |
| `rk3562-evb2-ddr4-v10-linux.dts` | Rockchip 原名 Linux 入口（与 `ek3562.dts` 同 include 集；对照用） |
| `rk3562-evb2-ddr4-v10.dtsi` | EVB2 DDR4 板级 |
| `rk3562-evb.dtsi` | EVB 共用板级 |
| `rk3562-evb2-cam.dtsi` | 摄像头 |
| `rk3562-linux.dtsi` | Linux 侧片段 |
| `rk3562-rk809.dtsi` | RK809 PMIC |
| `ek3562-wifibt.config` | `rtw88` / RTL8821CU Kconfig fragment |

**仍留在 owned `linux-sdk`（勿无故 fork）：** `rk3562.dtsi`、`rk3562-pinctrl.dtsi`、`rockchip-pinconf.dtsi`。

**不要** include ynh960 / `own-gpio` / `gpio_innohi` / Innohi ParamUpdate。

## FIT / OEM 接入清单（按序）

### A. Kernel Image（RK3562 进通用 Image）

- [ ] 确认 `overlay/kernel/**/*.config` 已覆盖 RK3562 所需驱动（至少对照现板 `6.1.118` 能力；Wi‑Fi 已有 `ek3562-wifibt.config`）
- [ ] 若新增/改过 SoC Kconfig：`make apply-overlay` 后 **`FORCE_KERNEL_IMAGE=1 make build-kernel`**
- [ ] 仅 DTB / FIT 清单变更、Image 已含 RK3562：plain `make build-kernel` 即可

### B. FIT 多 conf（W5）

- [ ] 在 `board/rk356x-fit-boards.txt` **追加一行** `ek3562`（产出 `fdt-ek3562` / conf `ek3562`）
- [ ] **在此之前不要** 把 `ek3562` 写进清单 — `make build-kernel` 会找 `ek3562.dtb`；Image 未就绪时会白烧时间
- [ ] `make apply-overlay` → `make build-kernel`
- [ ] `bash scripts/verify-boot-fit.sh output/firmware` — conf 列表含 `ynh960` + `ek3562`
- [ ] U-Boot 能选 FIT conf（见 §C）；清单进 FIT 后与 `board_id` 对齐

### C. U-Boot / MiniLoader（**自建**，非「禁止编译」）

有板级 DT 之后，正规路径是 Rockchip 公开树自建，再落入 `prebuilt/`。详见 **[`docs/uboot-rkbin.md`](../../docs/uboot-rkbin.md)**。

- [ ] Clone [rockchip-linux/rkbin](https://github.com/rockchip-linux/rkbin)；按 SoC/DDR 选 `RKBOOT/RK3562MINIALL*.ini`
- [ ] `./tools/boot_merger RKBOOT/<匹配>.ini` → 得到 `*_spl_loader_*.bin`（工具名 **boot_merger**）
- [ ] Clone [rockchip-linux/u-boot](https://github.com/rockchip-linux/u-boot)（或 `make fetch-uboot`）；用 **RK3562 EVB2** 对应 defconfig + 与 `ek3562.dts` 对照的板级 DT 编出 **`uboot.img`**
- [ ] 安装到 `prebuilt/bootloader/vendor-ek3562/{uboot.img,MiniLoaderAll.bin}`（见 `board/factory-skus.tsv` 行 `ek3562-dev`）；README 记下 ini / 版本 / git rev
- [ ] U-Boot 能选 FIT conf：`bootm <addr>#ek3562`（或 factory env）；默认 conf 仍可能是 `ynh960` 时须显式指定

### D. OEM / factory SKU

- [ ] `oem/packs/ek3562_panel-tbd/manifest.json`：`compat.fit_dt` 从 **`pending` → `ek3562`**（与 FIT conf / `board_id` 一致）
- [ ] 屏参：补 `oem/screens/panel-ek3562-tbd/`（或换真实 `screen_id` / pack）；LCD 运行时参在 OEM，**启动 DTB 仍只在 FIT**
- [ ] `FACTORY_SKU=ek3562-dev make build-oem` → 需要整机时再 `make build-img` / `make flash`
- [ ] 日常 OEM 迭代：`OEM_ONLY=1 make upgrade`

### E. Rootfs / 产品差异（按需）

- [ ] Wi‑Fi firmware：`overlay/buildroot/chips/lws_hmi_wifi_rtw88.config` + `bash scripts/br-make-packages.sh wifi linux-firmware` → `make build-rootfs`
- [ ] GPIO / Modbus / USB OTG：按真板改 HAL catalog + 必要时加 `ek3562-*.dtsi` 碎片（仿 ynh960），**不要**抄 ynh960 pinmux
- [ ] 产品 App 仍用 `APP=`；硬件差异走 OEM + DTB，不为 ek3562 fork rootfs

### F. 验收

- [ ] 串口：`PORT=/dev/cu.usbserial* make serial-console`（115200）见 FIQ / boot
- [ ] `cat /proc/device-tree/model` ≈ EVB2 DDR4 V10；`compatible` 含 `rk3562-evb2-ddr4-v10`
- [ ] Wi‑Fi / BT bring-up（OEM helper）；以太 / 屏 / 触控按 SKU
- [ ] ynh960 回归：同一 FIT 内 conf `ynh960` 仍可启动（通用 Image 未破坏 RK3566）
- [ ] 自建 loader+uboot：Maskrom/`make flash` 可进 Loader；冷启动进 Linux

## 日常命令（DT 已在 overlay 后）

```bash
make apply-overlay
# 仅 DTB / FIT 清单：
make build-kernel
# 若动过 ek3562-wifibt.config / 其它 *.config：
# FORCE_KERNEL_IMAGE=1 make build-kernel
make upgrade
```

Live FDT 抓取备份（可选）：`output/ek3562-dt/live.{dtb,dts}`（gitignored）。

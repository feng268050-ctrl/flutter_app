## GMAC / 有线网（对照 ynh960 踩坑）

ynh960 产品口是 **`&gmac1` RMII + `clock_in_out = "input"`**（PHY 驱动 REF_CLK；必须把 `SCLK_GMAC1` parent 到 `&gmac1_clkin`，不能只改字符串却仍让 SoC `assigned-clock-rates` 出 50 MHz —— 否则 ~0.5 Mbps / RTP 大量丢包）。见 `ynh960-uart5-gmac.dtsi`。

**ek3562（overlay + 现场 live FDT 一致）主口是另一路：**

| 项 | ek3562 `&gmac0`（当前 FIT DTB） | ynh960 `&gmac1`（量产） |
|----|-------------------------------|-------------------------|
| 模式 | **`rgmii-rxid`** | `rmii` |
| `clock_in_out` | **`output`**（SoC → PHY） | **`input`**（PHY → SoC） |
| tx_delay | `<0x42>`（rx 注释掉，走 rxid） | 删除（RMII） |
| PHY | mdio0 `phy@1`，`CLK_GMAC_ETH_OUT2IO` @ 25 MHz | mdio1 `phy@1` |
| 复位 | `gpio3 PC4` | `gpio4 PB3`（避开 UART5） |

现场 Android live FDT 另有 **`&gmac1` okay + RMII + `clock_in_out = "input"`**；当前 overlay **未启用 gmac1**（只有 EVB2 的 gmac0）。若板子第二路网口要用，须单独移植，并按 ynh960 规则配齐 `gmac1_clkin` parent，**不要**只翻 `clock_in_out`。

**不要**把 ynh960 的 `clock_in_out = "input"` 抄到 ek3562 的 gmac0 上。

RTSP 有线测速（仍在仓库）：

```bash
# SSH 上板测相机 RTSP remux 码率（ynh960 验收脚本；ek3562 同样可用）
STOP_SERVICES=1 scripts/measure-ip-camera-rtsp-ssh.sh 12
# 另见：scripts/measure-ip-camera-rtsp.sh / measure-ip-camera-rtsp-adb.sh
# 文档：docs/ip-camera-rtsp-bitrate-android-vs-linux.md
```

## GPIO / 丝印 IN* · OUT* · gpiod

完整台账：**[`docs/ek3562-io-pinmux-ledger.md`](../../../docs/ek3562-io-pinmux-ledger.md)**。

| 丝印 | linux# | gpiod | 物理 |
|------|--------|-------|------|
| OUT0–3 | 495–498 | `gpiochip6` offset **0–3** | PCA9535 P0–P3（`i2c1` `@0x20`，label `1-0020`） |
| IN0 | 113 | `gpiochip3` / **17** | GPIO3_PC1 |
| IN1 | 110 | `gpiochip3` / **14** | GPIO3_PB6 |
| IN2 | 50 | `gpiochip1` / **18** | GPIO1_PC2 |
| IN3 | 51 | `gpiochip1` / **19** | GPIO1_PC3 |

- OUT* = 扩展器；IN* = SoC（**不是** PCA 的 4–15）。丝印未必印 IN3/OUT3，系统已有线。
- App：`gpio.ek3562.json`（LED→OUT0–2，`aux_out3`→OUT3，button→IN0–3）。
- `gpio-product-off.sh` 按 `board_id` 分支拉低 OUT0–3。
- **勿** `gpio-hog` / `gpio-leds` 占这些脚。chip 序号可能随枚举变 —— 用 `gpiodetect` / label `1-0020` 核对。
